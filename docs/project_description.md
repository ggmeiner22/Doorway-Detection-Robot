This project implements a sensor fusion module for a wall-following robot based on a Bayesian Network. The robot navigates along a wall using its infrared sensors and a PID controller. As it moves, it uses a Bayesian Network to process sensor data over time to determine its current state, or "location" (e.g., `Wall`, `Door`, `Door_Passed`). The system continuously predicts its location, its distance from the wall, and whether it has recently passed a doorway. The Conditional Probability Tables (CPTs) that power the network are learned from data collected during manual runs of the robot.
