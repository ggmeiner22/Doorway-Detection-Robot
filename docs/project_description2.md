The project 2 is the continuation of project 1 where we developed an autonomous navigation system for a robot using a Partially Observable Markov Decision Process (POMDP) framework to execute a sequential mission where it must identify and count three specific doors on its right side, stop at the third location to perform a task such as cargo acquisition, and then autonomously return to its starting point, effectively managing the uncertainties inherent in sensor data and partial environmental observability to ensure robust task completion
